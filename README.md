<h1 align="center">DesignHub</h1>

#### DesignHub is a modern UI inspiration platform that helps developers and designers explore beautifully crafted interface designs. The platform features a collection of responsive and reusable UI components, making it easier to discover design ideas for web projects.

---

## UI Categories

- Login Pages
- Signup Pages
- Dashboard UI
- Landing Pages
- Forms UI
- UI Cards
- Pricing Pages
- Profile Pages

---

## Built With

- HTML5
- Tailwind CSS
- JavaScript (ES6)

---

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/Rohan-Korake/DesignHub.git
```

### 2. Navigate to the project folder

```bash
cd designhub
```

### 3. Start the Development Server

```bash
npm run dev
```
